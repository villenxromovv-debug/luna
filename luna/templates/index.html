1. FFmpeg, yt-dlp & Deno Runtime installed automatically

Running install.ps1 (Windows), install.sh (macOS/Linux), or Docker sets up Python dependencies, static-ffmpeg, yt-dlp, and the deno JavaScript runtime required for modern YouTube streams.

$ ffmpeg -version

Verify runtime health anytime under Settings → System Status → Check (FFmpeg & FFprobe, yt-dlp Engine, OpenCV Face Tracker, Media Directory Access, and Cookies YouTube).

2. AI API Keys (AI Short Clips Only) Settings / .env

Full HD Video, Video Trimmer, Instagram Reels, TikTok Clean, and Audio MP3 work immediately with zero API keys. For AI Short Clips, configure your provider in Settings (with Fetch Models and Test Connection):

  • Virality Ranking LLM: Supports OpenAI-compatible endpoints (OpenAI, OpenRouter, custom base URLs) or Google Gemini.
  • Speech Transcription Fallback: Checks local .srt cache and YouTube captions first; uses Groq Cloud Whisper, Gemini, or local Faster-Whisper only when captions are unavailable.
  • Privacy Boundary: Video downloads and FFmpeg cuts run locally; AI Short Clips only send transcripts (and audio when cloud transcription is used) to your configured provider.
3. YouTube Cookies (Bot & Age-Restricted Bypass) Settings upload / cookies.txt

If YouTube prompts sign-in verification or 403 throttling on restricted videos, export your browser cookies via Get cookies.txt LOCALLY and click Change next to Cookies YouTube in Settings (or place cookies.txt in the Luna root folder).

4. Optional Extras (Local Faster-Whisper & MCP Server) optional packages
$ pip install -r requirements-whisper.txt

faster-whisper is omitted from the default installer to keep downloads lightweight. Install requirements-whisper.txt inside your .venv to enable offline transcription, or requirements-mcp.txt to expose Luna tools via luna/mcp_server.py.

Rename Workspace

Click the pencil icon on any workspace to update its display name in meta.json and refresh the Workspace gallery instantly without breaking file links.

Move Storage Folder

Change the active storage root anytime from Settings → Media Storage → Move Folder to relocate or migrate future downloads to another drive.

Open Folder & Preview

Play MP4 clips or 320 kbps MP3s directly inside Workspace, download individual files or batch .ZIP archives, or open the workspace folder straight in your OS file explorer.

Safe Deletion

Deleting a workspace opens a confirmation modal first, then safely clears only files inside the configured storage root directory.

Why do I see the warning "Invalid URL"?

Luna checks that the link uses http:// or https://, resolves to a public host, and comes from YouTube, Instagram, or TikTok. Check the link and try again.

What if my computer does not have a D:\ drive?

If the D:\ drive is unavailable (or on macOS/Linux/Docker), Luna automatically uses the local output/ folder. You can move and migrate files anytime using Move Folder in Settings.

YouTube shows "Sign in to confirm you're not a bot"?

This happens when YouTube blocks an IP or requests account verification. Export your YouTube cookies with Get cookies.txt LOCALLY and upload the file directly in Settings (or save it as cookies.txt in the Luna root folder).

How do I configure an OpenAI-compatible API key?

Create a key in your provider's dashboard, enter the key and base URL in Settings, click Fetch Models to pick a chat model, and verify with Test Connection. Keys are saved directly to .env.

When should I choose Face Tracking or Center Crop?

Select Face Track for podcasts or interviews focused on one speaker so OpenCV keeps them centered. Leave the default Center Crop for faster rendering on vlogs with multiple moving people or screen recordings.
